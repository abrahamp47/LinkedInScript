# LinkedInScript

A Windows automation tool that monitors LinkedIn daily for new tech internship openings in Bangalore or remote positions. It filters for quality companies, tracks what you've already seen, and emails you a digest of new listings each day.

## Features

- **One-command setup** — `python setup.py` handles Python version check, venv, dependencies, Playwright, and config
- **Auto-managed LinkedIn auth** — Logs in via Playwright on first run, refreshes cookies headlessly every 30 days
- **Accurate intern filtering** — Authenticated API with experience level filter + title/description analysis rejects senior roles
- **55-company watchlist** — FAANG, top Indian startups, quant firms highlighted at top of digest
- **27-company blocklist** — Service companies (TCS, Infosys, etc.) and toxic employers auto-rejected
- **Smart filtering** — Location (Bangalore/Remote only), salary floor (30k/month), company quality
- **Deduplication** — SQLite-backed tracking with repost detection (same role reposted under new ID)
- **HTML email digest** — Sectioned output (watchlist first), with title, company, link, snippet, location, posted date
- **Unattended scheduling** — `python main.py --install` registers daily Task Scheduler job
- **Resilient** — Partial results on LinkedIn blocking, SMTP fallback to HTML file, DB auto-purge (90 days)
- **Compatible** — Works with Python 3.9–3.12 (auto-installs 3.12 if missing or incompatible)

## Setup

### Prerequisites

- Windows 10/11
- Python 3.9–3.12 (setup script installs 3.12 for you if missing or incompatible)
- Gmail account with 2-Step Verification enabled
- A LinkedIn account (for authenticated scraping)

### Step 1: Clone and install

```powershell
git clone https://github.com/abrahamp47/LinkedInScript.git
cd LinkedInScript
python setup.py
```

This single command:
- Checks your Python version (needs 3.9–3.12; installs 3.12 via winget if too old, too new, or missing)
- Creates a `.venv` virtual environment
- Installs all pip dependencies + Playwright Chromium
- Generates `config.yaml` from template

> **Note:** Python 3.13+ is not yet supported (numpy/pandas lack pre-built wheels). The setup script detects this and installs 3.12 automatically.

### Step 2: Configure email

Create a `.env` file in the project root:

```
EMAIL_PASSWORD=your16charpassword
```

Get an App Password from [myaccount.google.com/apppasswords](https://myaccount.google.com/apppasswords) (requires 2FA enabled).

Update `config.yaml`:
```yaml
email:
  enabled: true
  sender_email: "your.email@gmail.com"
  recipient_email: "your.email@gmail.com"
```

### Step 3: Verify and run

```powershell
.venv\Scripts\activate
python main.py --test-email   # Verify SMTP works
python main.py                # First real run
```

On first run, a Chromium browser window opens — **log in to LinkedIn once**. After login, the window closes automatically and your session is saved. You won't need to do this again for ~30 days (auto-refreshes headlessly).

### Step 4 (optional): Schedule daily runs

```powershell
python main.py --install
```

Registers a daily Windows Task Scheduler job at the time in `config.yaml` (default 08:00). If your PC was off at that time, runs at next boot.

## How Authentication Works

```
First run:  Playwright opens browser → you log in → session saved to data/
Daily runs: Headless Playwright loads saved session → extracts fresh cookie → scrapes
Every 30d:  Cookie auto-refreshes headlessly using saved browser state
If expired: Browser opens once more for re-login (rare, ~1x per year)
```

No manual cookie management. Just log in once and forget about it.

If you prefer manual control, set `LINKEDIN_LI_AT=<cookie>` in `.env` — this overrides auto-refresh entirely.

**If the session dies during an unattended (scheduled) run**, the tool can't open a
browser nobody is watching. Instead it logs a clear warning and **emails you a one-time
"LinkedIn login required" alert**. Just run `python main.py` once interactively to log in,
and daily runs resume automatically.

## Usage

```
python main.py                   # Scrape, filter, email digest
python main.py --verbose         # Print full job details to console
python main.py --dry-run         # Preview digest (no email, no DB writes)
python main.py --test-email      # Verify SMTP configuration
python main.py --status          # Show last run, failures, next scheduled time
python main.py --install         # Register daily Task Scheduler job
python main.py --uninstall-task  # Remove scheduled task only (keeps data)
python main.py --uninstall       # Remove everything (task, database, logs, config)
```

## Configuration

All settings in `config.yaml` (generated by `setup.py`):

| Section | What it controls |
|---------|-----------------|
| `search.keywords` | Job search terms (9 default intern variations) |
| `search.locations` | Target locations (Bangalore + India) |
| `companies.watchlist` | 55 priority companies — always included, salary filter waived |
| `companies.blocklist` | 27 rejected companies — auto-filtered out |
| `filters.min_salary_monthly` | Minimum salary threshold (default 30,000) |
| `filters.location_aliases` | Bangalore area neighborhoods |
| `filters.remote_keywords` | Remote work indicators |
| `email.*` | SMTP settings for digest delivery |
| `schedule.time` | Daily run time (24h format, default 08:00) |
| `database.retention_days` | Auto-purge old entries (default 90 days) |

## How It Works

```
LinkedIn (authenticated API)
    │
    ▼
Scraper (python-jobspy + f_E=1,2 experience filter)
    │
    ▼
Experience Filter ──→ rejects Senior, Lead, Engineer II/III, 3+ yrs
    │
    ▼
Location Filter ──→ keeps only Bangalore / Remote
    │
    ▼
Company Filter ──→ rejects blocklist, flags watchlist
    │
    ▼
Salary Filter ──→ rejects < 30k/month (watchlist exempt)
    │
    ▼
SQLite Dedup ──→ only new jobs pass, reposts labeled
    │
    ▼
Email Digest ──→ watchlist section first, then general listings
```

## Error Handling

| Scenario | What happens |
|----------|-------------|
| Some searches blocked | Proceeds with partial results, warning in email footer |
| All searches blocked | Skips email, health monitor tracks the failure |
| SMTP fails | Saves digest to `output/digest-YYYY-MM-DD.html`, jobs re-queued |
| Previous email failed | Next successful email notes the saved fallback |
| 2+ consecutive failures | Sends health alert email |
| PC was off at run time | Runs at next opportunity (StartWhenAvailable) |
| LinkedIn cookie expired | Auto-refreshes headlessly using saved browser state |
| LinkedIn session dead (unattended run) | Emails a one-time "login required" alert; run `python main.py` once to fix |

## Uninstall

```
python main.py --uninstall-task  # Remove scheduled task only (keeps your data)
python main.py --uninstall       # Remove everything: task, database, logs, output, config
```

Source code is always preserved. To reinstall from scratch, run `python setup.py` again.
